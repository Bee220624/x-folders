执行方式：用户在自己的 Chrome 里从 `dist/chrome-mv3` 加载扩展；经用户授权，Claude 用 Claude in Chrome
在已登录的 x.com 上操作并检查；第 10、11 项由用户在浏览器侧边栏中亲自操作并确认。全程没有点赞、转帖、
书签、发帖，也没有修改任何设置。

### 发现的缺陷与修复

| 缺陷 | 现象 | 根因 | 修复提交 |
|---|---|---|---|
| A | 矮窗口下账号切换按钮被挤出屏幕 | 高度预算有 120px 下限，且只限制树、不含标题与边距 | `775c4a9` |
| B | 带跟踪标记的普通帖子没有按钮 | 把 `placementTracking` 当作广告的唯一判据，而 X 也会把它加在普通帖子上 | `b571e04` |
| C | 窄屏面板盖住右键菜单；确认框第一次点击无效 | 面板层级高于菜单和对话框，且与菜单共用「点外面关闭」层 | `27c89ce` |
| D | 页面内收藏列表打开时，窄屏面板被列表挡住 | X 的导航位于 z-index 0 的层叠上下文里，其中的元素无法高过页面级覆盖层 | `77ddce3` |

每个缺陷都先在自动化测试中复现（单元或端到端），修复后测试通过；A 的端到端测试另做了变异检查，
恢复旧逻辑后测试确实失败。

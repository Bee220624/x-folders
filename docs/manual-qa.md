### 发现的缺陷与修复

| 缺陷 | 现象 | 根因 | 修复提交 |

| A | 矮窗口下账号切换按钮被挤出屏幕 | 高度预算有 120px 下限，且只限制树、不含标题与边距 | `775c4a9` |

### 用户反馈（转入 M3）

用户看过富卡片后指出：点「显示更多」或视频的播放标记会跳到原帖，而且是整页重新加载，不像 X 原生那样流畅。
2026-10-01 的决定（已写入工单 2.3、2.4 与修订说明第 17 条）：

- 做：打开原帖改为 X 页面内切换，不整页重新加载；
- 做：已补全的长帖在卡片里先折叠，点「显示更多」在卡片内展开；
- 不做：GIF 在卡片内播放；
- 做不到：普通视频在卡片内播放——插件拿不到可播放的视频地址，打开原帖后由 X 的播放器播放。

### 其他观察

- 窄屏的文件夹面板开着时，点页面别处的第一下只关闭面板，和 X 自己的菜单一致。
- 页面不可见时（窗口被挡住或最小化、标签页在后台）扩展按设计暂停：原帖页必须显示在屏幕上才会补全。
- Chrome 开着页面翻译时，保存的是页面上显示的译文（抓样本时在正文里见到翻译插入的 `<font>`）。
- 抓样本时发现：直接挂在 x.com 页面上的下载链接会被 X 的链接处理拦住，采集脚本已改为把它放进封闭的
  Shadow Root。
